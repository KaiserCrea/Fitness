FITNESS PWA - V0

Contenu :
- index.html
- styles.css
- app.js
- manifest.webmanifest
- service-worker.js

Fonctions déjà présentes :
- Première installation : semaine A/B/C + prochaine séance G1/G2/G3
- Onglets Aujourd'hui / Programme / Progression / Historique
- Cycle G hebdomadaire de base
- Réussi / Échoué / Non réalisé
- Demande de prochaine référence après Réussi
- Heure début/fin et calcul de durée
- Historique local
- Programme consultable et ordre modifiable
- Séances ATH A/B et Full Mix intégrées comme données
- Design noir/doré sans slogans
- Stockage local via localStorage
- Service worker et manifeste PWA

Pour tester localement :
1. Décompresser le dossier.
2. Lancer un petit serveur HTTP dans ce dossier, par exemple :
   python -m http.server 8080
3. Ouvrir http://localhost:8080 dans un navigateur.

Important :
Cette V0 est un squelette fonctionnel. Les images/fiches techniques validées ne sont pas encore intégrées au package.
